# 笔记规范

## 命名

`NN-短横线标题.md`，NN 与系列篇号一致（01–13）。

## 每篇必须带的头部

```yaml
---
篇号: 05
标题: 上下文管理：会话、压缩、追加式 trace
上游版本: v0.2.2-rc.1
锁定提交: fcc0ad462172522aaf5c93a7b2e01f6b9f0b0159
涉及模块: packages/session, packages/compaction, packages/context
状态: 草稿
---
```

## 正文结构

1. **这篇要回答的问题**（一句话，对应头条文章的开头钩子）
2. **先看结论**（3 条以内，先给判断再给证据）
3. **源码走读**（关键文件路径 + 行号范围 + 片段，每段代码后面跟一句「所以它这么做是为了……」）
4. **反例 / 边界情况**（换个做法会怎样，这是区别于官方文档的核心）
5. **可复现步骤**（对应 `code/NN/` 下的脚本）
6. **头条成稿映射**（这一节对应文章哪几个小标题，配图放哪）

## 引用代码的要求

- 必须写清文件路径，格式：`packages/core/agent-loop/src/xxx.ts:120-148`
- 大段引用保留 MIT 原始版权头
- 不要粘贴整文件，只贴论证需要的片段
